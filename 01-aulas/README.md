## Notas de estudo

**Aula 02 — Infraestrutura.** Abre o desafio inicial com dados abertos do gov.br.
Os desafios derivados estão em [`03-desafios/`](../03-desafios/).

**Aula 03 — ETL e MapReduce.** O arquivo
[`aula-03-exemplo-schema.sql`](aula-03-exemplo-schema.sql) é um schema MySQL de
exemplo (médicos, países, produtos, pedidos, comerciantes) usado para praticar
modelagem relacional, chaves estrangeiras e índices — a base "operacional" de onde
o ETL extrai dados. Para revisar SQL do zero, veja o
[minicurso de SQL](../05-recursos/minicurso-de-sql.pdf).

**Aulas 04, 06 e 07 — Observatório de Dados.** Formam um bloco contínuo: a aula 04
apresenta o conceito e as aulas 06–07 mostram o desenvolvimento. Leitura de apoio:
[artigo sobre Big Data e Open Data nas Smart Cities](../05-recursos/artigo-big-data-e-open-data-nas-smart-cities.pdf).

**Aula 08 — Educação no Brasil.** Conecta diretamente com o desafio de
[Educação em Olinda](../03-desafios/educacao-olinda/).

> Os slides da aula 02 estão em `.pptx` (as demais aulas estão em PDF).
> Não há material de slides para a aula 01.
