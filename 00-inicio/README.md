responde às perguntas que vêm **antes** dos slides — o que é a disciplina, para que
ela serve na sua carreira, e como estudar sem se perder.

## Roteiro da primeira semana

1. Leia [`sobre-a-disciplina.md`](sobre-a-disciplina.md) — 10 minutos, dá o mapa inteiro.
2. Veja como você é avaliado em [`../04-avaliacoes/README.md`](../04-avaliacoes/README.md).
   Duas notas: projeto (60%) e prova escrita (40%).
3. Abra os slides da [aula 00](../01-aulas/aula-00-apresentacao-da-disciplina.pdf).
4. Confirme em qual grupo você está: [`../04-avaliacoes/turma.md`](../04-avaliacoes/turma.md).
5. Monte seu ambiente seguindo [`ferramentas.md`](ferramentas.md) — no começo,
   só o Google Colab já basta.
6. Deixe o [`glossario.md`](glossario.md) aberto durante as aulas. Boa parte da
   dificuldade inicial em Big Data é vocabulário, não conceito.

## Uma coisa só, se você só ler uma

Big Data não é sobre ter muitos dados. É sobre o que fazer quando o volume, a
velocidade ou a variedade dos dados quebram a ferramenta que você usaria
normalmente. Toda a disciplina é a resposta a essa pergunta.
