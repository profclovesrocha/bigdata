# Big Data — UNINASSAU Olinda

Repositório da disciplina de **Big Data**: slides, notebooks, desafios práticos e
material de apoio. Docente: **Prof. Mentor Cloves Rocha**.

> **Primeira vez aqui?** Comece por [`00-inicio/`](00-inicio/) — o que é a
> disciplina, como estudar e para que isso serve na sua carreira.

---

## Estrutura

As pastas são numeradas na ordem em que você deve usá-las.

| Pasta | O que tem dentro |
| --- | --- |
| [**00-inicio/**](00-inicio/) | Sobre a disciplina, como estudar, mercado de trabalho, ferramentas e glossário |
| [**01-aulas/**](01-aulas/) | Slides e exemplos de código, um arquivo por aula |
| [**02-notebooks/**](02-notebooks/) | Notebooks Jupyter/Colab escritos em sala |
| [**03-desafios/**](03-desafios/) | Desafios práticos e projetos avaliativos |
| [**04-avaliacoes/**](04-avaliacoes/) | Notas, cronograma, calendário e grupos da turma |
| [**05-recursos/**](05-recursos/) | E-book, minicurso de SQL, artigos e fontes de dados |

Dentro de `01-aulas/`, os arquivos seguem o padrão `aula-NN-tema.ext` — a ordem
alfabética é a ordem cronológica do curso.

| Bloco | Aulas | Do que se trata |

| Dados e processamento | 03 | Banco de dados operacional, ETL e MapReduce |
