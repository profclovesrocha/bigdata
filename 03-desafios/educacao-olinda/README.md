# Desafio — Educação em Olinda (PE)

Analisar a evolução da educação básica do município de Olinda entre 2014 e 2024 a
partir de dados públicos, identificando problemas e propondo indicadores.

## Ponto de partida

A dinâmica em sala levantou como principais problemas percebidos: **infraestrutura**,
**desigualdade**, falta de manutenção, carência de material, notas abaixo da meta,
alfabetização e deslocamento dos alunos. Use esses temas como hipóteses e tente
confirmá-las (ou refutá-las) com os números do relatório.
